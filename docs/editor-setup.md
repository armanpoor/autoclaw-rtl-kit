# راه‌اندازی محیط‌ها

## AutoClaw

دو کار، هر دو اختیاری، هر دو بی‌خطر:

۱. **قاعدهٔ دائمی.** اگر پروژه‌تان فایل دستور عامل دارد (`CLAUDE.md`، `AGENTS.md` یا مشابه)، قطعهٔ [prompt/autoclaw-rtl-law.md](../prompt/autoclaw-rtl-law.md) را به آن اضافه کنید. از آن پس هر پاسخ با بستهٔ جهت‌دار می‌آید.

۲. **خواندن متن‌های قدیمی.** متن به‌هم‌ریخته را کپی کنید و در [لوح راست‌چین](../tools/rtl_paddle.html) بچسبانید، یا از دستور `python tools/rtl_view.py --clipboard` استفاده کنید.

نکته: بستهٔ جهت‌دار فقط وقتی اثر می‌کند که رندرکننده تگ اچ‌تی‌ام‌ال را عبور دهد. آزمون سریع در [پرسش‌های متداول](troubleshooting.md#تگها-بهصورت-متن-دیده-میشوند) آمده است.

## VS Code

پیش‌نمایش داخلی مارک‌داون پایهٔ جهت را از محتوا تشخیص نمی‌دهد. سه گزینه:

| گزینه | مناسب برای |
|---|---|
| افزونهٔ Persian RTL Markdown Preview | ساده‌ترین راه؛ فونت هم همراه دارد و کد را چپ‌به‌راست نگه می‌دارد |
| افزونهٔ BidiMD | مشابه، با تمرکز روی بلوک‌های کد |
| استایل دستی | وقتی افزونه نصب نمی‌کنید |

برای گزینهٔ سوم، یک فایل `rtl-preview.css` در ریشهٔ پروژه بسازید:

```css
body, p, li, td, th, blockquote { direction: rtl; unicode-bidi: plaintext; text-align: right; }
pre, code { direction: ltr; unicode-bidi: isolate; text-align: left; }
```

و در تنظیمات VS Code:

```json
{
  "markdown.styles": ["./rtl-preview.css"]
}
```

محدودیت این روش: تشخیص خودکار جهت برای هر پاراگراف انجام نمی‌شود؛ برای متن کاملاً فارسی کافی است.

## GitHub

کاری لازم نیست. از نوامبر ۲۰۲۱ مارک‌داون، ایشو، پول‌ریکوئست و کامنت به‌صورت بومی جهت را تشخیص می‌دهند. اگر خواستید جهت را صریح کنید، همان بستهٔ `div dir="rtl"` کار می‌کند.

## ترمینال

ترمینال‌های متنی به‌طور کلی از الگوریتم دوجهته پشتیبانی نمی‌کنند. درخواست رسمی برای ترمینال ویندوز از ۲۰۱۹ باز مانده است. توصیه: خروجی فارسی را در ترمینال نخوانید؛ آن را به فایل بدهید و در مرورگر باز کنید:

```bash
python tools/rtl_view.py report.md
```

## Obsidian

افزونهٔ Persian RTL Smart Direction جهت هر پاراگراف را خودکار تنظیم می‌کند.

## Microsoft Word

ورد از دیرباز پایهٔ جهت را در سطح پاراگراف و سلول جدول مدیریت می‌کند؛ متن فارسی در آن درست است. اگر از این کیت به ورد کپی می‌کنید، نویسه‌های نامرئی (RLM/RLI) را قبل از چسباندن حذف کنید تا در جست‌وجو و شمارش کلمات مزاحم نشوند.
