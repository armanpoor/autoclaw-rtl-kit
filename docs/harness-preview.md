# پیش‌نمایش فایل‌های مارک‌داون در هارنس‌ها

## اصل ماجرا

تگ `<div dir="rtl">` که **داخل خود فایل** باشد، همراه فایل سفر می‌کند. هر ابزاری که مارک‌داون را به اچ‌تی‌ام‌ال تبدیل کند — پیش‌نمایش AutoClaw، پیش‌نمایش VS Code، گیت‌هاب، آبسیدین — آن تگ را می‌بیند و پایهٔ جهت را راست می‌کند. پس لازم نیست منتظر پشتیبانی رسمی هیچ نرم‌افزاری بمانید.

| ابزار | رفتار با فایل بسته‌بندی‌شده |
|---|---|
| پیش‌نمایش AutoClaw | درست، اگر مارک‌داون را رندر کند |
| پیش‌نمایش VS Code | درست، در حالت پیش‌نمایش |
| گیت‌هاب | درست، با پشتیبانی بومی و همان بسته |
| آبسیدین | درست، در حالت خواندن |
| ادیتور خام (بدون پیش‌نمایش) | اثری ندارد؛ متن خام همیشه چپ‌چین است |
| ترمینال | اثری ندارد؛ ترمینال جهتی نمی‌شناسد |

## آزمون بیست‌ثانیه‌ای

یک فایل نمونه بسازید و پیش‌نمایشش را باز کنید:

```markdown
<div dir="rtl">

# عنوان آزمایشی

متن فارسی با پرانتز (AFR) و ضریب 0.375.

</div>
```

اگر تیتر و متن راست‌چین دیده شد، محیط شما مارک‌داون را رندر می‌کند و بسته اثر می‌گذارد. اگر خود تگ‌ها را دیدید، آن پیش‌نمایش متن خام نشان می‌دهد و راه‌حل، باز کردن فایل در مرورگر است.

## خودکارسازی

نگهبان، پوشه را می‌گردد و هر فایل فارسیِ بدون بسته را پیدا می‌کند:

```bash
python tools/rtl_guard.py .              # گزارش
python tools/rtl_guard.py . --write      # بسته‌بندی خودکار
python tools/rtl_guard.py . --watch      # پایش پیوسته
python tools/rtl_guard.py . --check      # درگاه انطباق برای CI
```

برای رد کردن فایل‌هایی که نباید بسته شوند (مثل فایل دستور عامل یا قطعه‌های پرامپت)، کنار مخزن یک فایل `.rtlignore` بگذارید:

```
CLAUDE.md
AGENTS.md
prompt/*.md
```

## VS Code

پیش‌نمایش داخلی، استایل پروژه را می‌خواند. دو فایل در ریشهٔ مخزن بگذارید:

`rtl-preview.css`

```css
body, p, li, td, th, blockquote { direction: rtl; unicode-bidi: plaintext; text-align: right; }
pre, code { direction: ltr; unicode-bidi: isolate; text-align: left; }
```

`.vscode/settings.json`

```json
{
  "markdown.styles": ["./rtl-preview.css"]
}
```

این روش برای متن فارسی کافی است. اگر تشخیص خودکار جهت برای هر بلوک را می‌خواهید، افزونهٔ Persian RTL Markdown Preview را نصب کنید.

## چرا فایل‌های دستور عامل مستثنا هستند

فایل‌هایی مثل `CLAUDE.md` را مدل به‌عنوان متن خام می‌خواند، نه انسان در پیش‌نمایش. بسته‌بندی‌کردنشان فقط دو سطر اچ‌تی‌ام‌ال به هر پرامپت اضافه می‌کند و سودی ندارد. همین دلیل برای قطعه‌های آماده در پوشهٔ `prompt/` هم صادق است؛ آن‌ها باید عیناً کپی شوند، نه با تگ اضافه.
